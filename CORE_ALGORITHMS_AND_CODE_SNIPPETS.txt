================================================================================
1. ALGORITHM 1: SHANNON INFORMATION ENTROPY CALCULATION
================================================================================
1.1 Objective:
Detect randomly generated, machine-produced (DGA), or obfuscated malicious domains.

1.2 Mathematical Formulation:
H(X) = - SUM [ P(x_i) * log2(P(x_i)) ]
Where:
- X is the analyzed domain/netloc string.
- x_i is each unique character in the string.
- P(x_i) is the probability of occurrence of character x_i in string X.

1.3 Input & Output:
- Input: Domain / Hostname string (e.g., "x89j12kzlq.xyz" or "wikipedia.org")
- Output: Entropy value (float). Normal domains: 2.2 - 3.4; Malicious DGA: > 3.8

1.4 Core Logic (Python):
--------------------------------------------------------------------------------
import math

def calculate_entropy(text: str) -> float:
    """Computes Shannon entropy to measure string randomness and detect DGA domains."""
    if not text:
        return 0.0
    entropy = 0.0
    length = len(text)
    for char in set(text):
        p_x = text.count(char) / length
        if p_x > 0:
            entropy -= p_x * math.log2(p_x)
    return round(entropy, 3)

2. ALGORITHM 2: URL STRUCTURAL PARSING & BRAND SPOOFING DETECTION
================================================================================
2.1 Objective:
Identify brand impersonation attacks where trusted company names (PayPal, Chase,
Apple, etc.) are injected into subdomains or paths to trick users.

2.2 Core Logic Principle:
If Brand exists in (Subdomain + Path) BUT Brand DOES NOT EXIST in the Registered
Root Domain, then classify as HIGH-RISK BRAND SPOOFING.

2.3 Input & Output:
- Input: Raw URL string, list of high-profile targeted brands.
- Output: Dictionary containing boolean flags (`has_ip_host`, `is_brand_spoofed`),
  detected spoofed brand names, protocol encryption status, and root domain.

2.4 Core Logic (Python):
--------------------------------------------------------------------------------
import re
from urllib.parse import urlparse
import tldextract

def detect_brand_spoofing_and_structure(url: str, targeted_brands: list) -> dict:
    """Extracts structural anomalies, brand impersonation, and raw IP hostnames."""
    parsed = urlparse(url if url.startswith(('http://', 'https://')) else 'http://' + url)
    ext = tldextract.extract(url)

    root_domain = ext.domain.lower()
    subdomain_and_path = (ext.subdomain + " " + parsed.path).lower()
    netloc = parsed.netloc.lower()

    # Check 1: Raw IP Address Host Pattern (e.g. http://192.168.1.1/login)
    has_ip_host = bool(re.match(r'^(\d{1,3}\.){3}\d{1,3}(:\d+)?$', netloc))

    # Check 2: Brand Impersonation in Subdomain / Path
    is_brand_spoofed = False
    spoofed_brands = []
    for brand in targeted_brands:
        if brand in subdomain_and_path and brand != root_domain:
            is_brand_spoofed = True
            spoofed_brands.append(brand)

    # Check 3: Connection Encryption Protocol
    is_https = (parsed.scheme == 'https')

    return {
        "has_ip_host": has_ip_host,
        "is_brand_spoofed": is_brand_spoofed,
        "spoofed_brands": spoofed_brands,
        "is_https": is_https,
        "root_domain": root_domain
    }

3. ALGORITHM 3: HYBRID MULTI-TIER AI + HEURISTIC THREAT DECISION MATRIX
================================================================================
3.1 Objective:
The central decision-making brain of AI Cyber Shield. Solves the limitation of
pure Machine Learning (which misses novel zero-day attacks) by combining Random
Forest probabilistic predictions with deterministic security rules.

3.2 Decision Hierarchy:
- Tier 1: Authority Whitelist -> Immediate SAFE (avoid false positives).
- Tier 2: Critical Threat Red Flags (Brand Spoof OR IP Host OR Suspicious TLD + Keywords)
          -> Immediate DANGEROUS (overrides ML model).
- Tier 3: Machine Learning Inference (Random Forest `predict_proba`) -> SUSPICIOUS or DANGEROUS.
- Tier 4: Default Safe verification.

3.3 Input & Output:
- Input: Feature dictionary from URL parsing, trained ML model pipeline, raw URL string.
- Output: Final Security Verdict (`status`: 'safe', 'suspicious', 'dangerous'),
  Confidence Score (0.00 - 1.00), and Detection Reasoning.

3.4 Core Logic (Python):
--------------------------------------------------------------------------------
def hybrid_threat_decision_engine(features: dict, ml_model, raw_url: str) -> dict:
    """Arbitrates final security verdict by combining ML inference with security rules."""
    
    # 1. Run Machine Learning Model Inference (Random Forest)
    ml_label = 'safe'
    ml_confidence = 0.85
    if ml_model:
        probs = ml_model.predict_proba([raw_url])[0]
        max_idx = probs.argmax()
        ml_label = ml_model.classes_[max_idx]
        ml_confidence = float(probs[max_idx])

    # 2. Evaluate Critical Threat Red Flags
    has_critical_red_flags = (
        features['has_ip_host'] or
        features['is_brand_spoofed'] or
        (features['has_suspicious_tld'] and features['keyword_count'] >= 1) or
        (features['keyword_count'] >= 2 and not features['is_https'])
    )

    # 3. Decision Arbitration Matrix
    if features.get('is_trusted_authority', False) and not features['is_brand_spoofed']:
        verdict = 'safe'
        confidence = max(0.95, ml_confidence)
        reason = "Verified authentic legitimate domain authority"
    elif has_critical_red_flags or ml_label == 'dangerous':
        verdict = 'dangerous'
        confidence = max(0.92, ml_confidence)
        reason = "Malicious phishing patterns and brand deception indicators detected"
    elif features.get('is_shortener', False) or features.get('has_suspicious_tld', False) or ml_label == 'suspicious':
        verdict = 'suspicious'
        confidence = max(0.78, ml_confidence)
        reason = "Unverified redirection or high-risk domain structure detected"
    else:
        verdict = 'safe'
        confidence = max(0.88, ml_confidence)
        reason = "Standard domain structure; no threat indicators identified"

    return {
        "status": verdict,
        "confidence": round(confidence, 2),
        "reason": reason
    }
